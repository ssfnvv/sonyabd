# Сайт для Сони

## Где что
- `/contribute` — форма для друзей (имя → карточка / голосовое / викторина / предсказание / видео)
- `/admin` — модерация (пароль из `ADMIN_PASSWORD`)
- `/`, `/act1`…`/act6` — сам подарок (в работе)
- `src/content/copy.ts` — **все тексты сайта** в одном файле. `// NEW` — фразы, которые ещё надо согласовать.
- `supabase/schema.sql` — схема базы, запускается один раз

## Запуск с нуля
1. Supabase: новый проект (регион Frankfurt) → SQL Editor → вставить `supabase/schema.sql` → Run.
2. Vercel: импортировать репозиторий из GitHub, добавить переменные из `.env.example`.
3. Готово: ссылка для друзей — `https://<проект>.vercel.app/contribute`.
